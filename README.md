# Dzũ ToolHub

Local-first modular web app for game assets, video transcripts and content creation.

## Initial direction

- React + TypeScript + Vite dashboard running locally.
- Tilemap Studio: terrain and 47-tile tools.
- Sprite Studio: animations and layered character assets.
- Transcript Studio: persistent video transcript history and cache.
- Content Studio: metadata, summaries and scripts.
- Asset workspace: safe export then optional cleanup.
- Future self-hosted HTTPS access, not required for local MVP.

See upcoming AGENTS.md and docs for implementation details.
