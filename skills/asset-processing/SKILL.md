# Asset Processing Skill

Use for tilemaps, pixel art, spritesheets and Godot exports.

- Separate artwork generation from autotile algorithms.
- Validate 8-neighbor corner-constrained masks and expected 47 variants.
- Check tile size, bounds, alpha, seams, palette and nearest-neighbor scaling.
- Preview transitions on varied maps before exporting.
- For sprites, preserve pivots, frame sizes and layer ordering in eight directions.
- Export deterministic PNG atlas plus metadata. Verify engine formats against target Godot version.
- Verify licenses before reusing third-party code/assets.
